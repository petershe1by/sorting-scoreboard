# 智能分拣裁判计分台

按校内智能分拣竞赛规则 V1.1 结算。打开 `index.html` 即可使用，也可从 GitHub Pages 托管同一文件。

- **快速汇总**适合已核对主盒的轮次。录入单件主盒数、两件主盒数和主盒合格显示条数。
- **逐盒核分**根据真实模型与颜色选主盒。先排除混装盒，同类按完整合格件数择优，同数取小盒号。逐盒的合格显示条数由裁判核验后录入。
- **保存本轮**后才更新成绩榜。仅录入一轮的队伍显示暂定名次。缺席或判罚零分可单独记录。取消资格的队伍保留原始记录，排名时排除。
- **成绩榜**先比较较好轮，再比较另一轮。每轮依次比较原始分、归盒分、合格件数和用时。两轮完全相同并列，名次按 1、1、3 的形式显示。
- **备份 JSON**保存本浏览器已保存的队伍与轮次，可在另一设备导入。**导出 CSV**用于查看和归档。临时试算或尚未保存的草稿不会写入备份或成绩榜。

计分与存储均在浏览器执行。公开仓库只包含网页代码，实际队伍和成绩由裁判现场录入。
